## Лабораторная работа №2: Камера и освещение

Сцена: три тора из лабораторной №1 и пол, освещение по модели Блинна–Фонга
(Vulkan, GLSL, ImGui). Выполнено базовое задание и все дополнительные задания (1–4).

- **Камера** — свободная: позиция, поворот (yaw/pitch), угол обзора, near/far,
  перспективная или ортографическая проекция. Матрица вида V = C⁻¹ = Rx(pitch) · Ry(−yaw) · T(−position).
- **Нормали** генерируются процедурно для тора, сферы и плоскости ([source/geometry.cpp](source/geometry.cpp)).
- **Освещение** во фрагментном шейдере ([shaders/lit.frag](shaders/lit.frag)): рассеянный свет,
  один направленный источник, массив точечных источников и массив прожекторов.
  Для точечных источников и прожекторов затухание 1/D², у прожекторов мягкие края между внутренним и внешним углом.
- **Наборы дескрипторов**: набор 0 — сцена (uniform-буфер + два storage-буфера с источниками),
  набор 1 — модель (матрица модели, матрица нормалей, материал). Storage-буферы растут
  автоматически, максимального числа источников в шейдере нет.
- **Визуализация источников**: сферы цвета источника и белые линии конуса для прожекторов,
  без освещения; показ и скрытие — в интерфейсе.
- Через интерфейс можно добавлять и удалять источники, менять материал (альбедо, цвет блика, блеск)
  и трансформацию объектов. Точечные источники можно анимировать (вращение вокруг оси Y).

### Управление

- Правая кнопка мыши + движение мыши — поворот камеры
- W/A/S/D — вперёд/влево/назад/вправо, Q/E — вниз/вверх, Shift — быстрее
